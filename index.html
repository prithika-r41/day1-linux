Linux modules

1. Shell and files

  • /etc config, /var logs, /usr programs
  • Hard link = same data; ln -s breaks if original is deleted
  • mkdir -p proj/{src,docs,tests}
  • vim: i, Esc, :wq, :q!

2. Text and pipes

  • stdin 0, stdout 1, stderr 2
  • > overwrite, >> append, 2>&1
  • grep -rin, sort | uniq -c, awk, sed
  • find . -mtime -1

3. Users and permissions

  • usermod -aG: keep the -a
  • setgid 2770: files inherit the group
  • Sticky bit: only owner or root deletes in /tmp
  • Edit sudo rules only with visudo
